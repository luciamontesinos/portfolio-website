This was a side project I did to learn more about creating interactive audio-visual projects in Processing using a MIDI keyboard. 

I am using WebMidi.js and p5.js to transform music into live visuals. Currently, I use the note, octave, attack, and duration of each note pressed to change the appearance of the shape by manipulating tone, saturation, bumps, and spherical coordinates. Additionally, the shape rotates to the BPM of the music.
